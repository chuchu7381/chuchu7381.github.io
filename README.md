# 🔎 快速查找資料小工具

提供常用資料夾與工作資源的一鍵開啟功能，減少使用者在公槽與資料夾間來回搜尋的時間。

## 功能特色

- ✅ 一鍵開啟多個常用網頁或資料夾
- ✅ 可勾選需要的項目後批次開啟
- ✅ 支援全選功能
- ✅ 依資料類型分類顯示
- ✅ 提升日常作業效率

## 使用方式

1. 勾選需要開啟的資料項目。
2. 點選「開啟選擇的資料夾」。
3. 若瀏覽器跳出「彈出式視窗已封鎖」訊息，請允許此網站開啟彈出式視窗。
4. 系統將自動開啟所有已勾選的連結。
